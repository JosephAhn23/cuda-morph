ascend_compat · cuda-morph v0.9.1

Run CUDA code on any accelerator, unchanged.

A thin compatibility bridge that intercepts torch.cuda at the source and routes it to whatever silicon is actually in the box — Ascend NPU, ROCm, Intel, Cambricon, or plain CPU. Not a rewrite. Not a fork of PyTorch. One import.

Four-layer stack

The shim sits between your code and torch_npu.

torch_npu already does the hard part — C++ dispatch, CANN, ACL. cuda-morph fixes the last mile: the existing CUDA-assuming Python that hard-codes torch.cuda calls all over your codebase.

Backend registry

One protocol, six device types.

Every vendor backend implements the same BackendInfo interface — the shim reads it to translate calls without knowing anything vendor-specific.

Command line

Thirteen subcommands, one entry point.

cuda-morph checkScan a script for CUDA calls that won't port cleanly.
cuda-morph portRewrite hard-coded torch.cuda calls in place.
cuda-morph doctorValidate the environment: CANN, torch_npu, driver versions.
cuda-morph verifyRun correctness checks against a target device.
cuda-morph benchReproduce the shim-overhead and op-latency suite.
cuda-morph runLaunch an existing script unchanged, shim pre-activated.
cuda-morph vllmPatch and launch vLLM serving on a non-CUDA backend.
